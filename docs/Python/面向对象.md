## 简介

一种编程范式

- 类：对一类拥有相同属性的对象的抽象、蓝图、圆形。（首字母大写，驼峰）
- 对象：类的实例，用模板生成的实体。

        print("血量：", self.__life)
        
        
person2 = Person2("xml")

## 进阶

### 类方法

通过`@classmethod`装饰器实现，和普通方法区别是类方法只能访问。变量，不能访问实例变量。Why？因为self这个参数接受的不是实例本身，而是类本身。有什么用？

```py
# 类方法：不能访问实例变量，只能访问类变量
class Cat:
    name = "mimi"  # 类变量

    def __init__(self, name):
        self.name = name

    @classmethod
    def eat(cls):
        print(f"{cls.name} is eating")


cat = Cat("jj")  # 传入的是实例变量
cat.eat()  
# 结果：mimi is eating
```

### 静态方法

`@staticmethod`不能访问类变量，也不能访问实例变量。静态方法隔断了它与类或实例的任何关系。

```py
# 静态方法
class Stu:
    def __init__(self, name):
        self.name = name

    @staticmethod
    def fly(self):
        print(f"{self.name} is flying")


    @staticmethod
    def eat():
        print("shit")

Stu.eat()  # 不用实例化，直接调用，输出shit
s = Stu("pym")
s.fly(s)  # 需要将实例传入其中
# 结果：pym is flying
```

### 属性方法

`@property`把一个方法变成一个静态的属性（变量）

```py
# 属性方法
class Stu2:
    def __init__(self, name):
        self.name = name

    @property
    def fly(self):
        print(f"{self.name} is flying")


s2 = Stu2("zyj")
s2.fly  # 不加括号
# 结果：zyj is flying
```

### 反射

通过字符串的形式来操作对象的属性

增删改查<img src="/python/面向对象/面向对象.assets/image-20240205230347950.png" alt="image-20240205230347950" style="zoom:50%;" />

```py
# 反射
class Per:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def f(self):
    print(f"{self.name} is speaking")


def f2(self):
    print(f"{self.name} is talking")


p = Per("xml", 23)
print(hasattr(p, "name"))  # 判断
# True
print(getattr(p, "age"))  # 取值/方法
# 23
setattr(p, "sex", "male")  # 增加属性
print(p.sex)
# male
setattr(p, "speak", f)  # 增加方法，f需先写好，与实例绑定
p.speak(p)  # 此处需要将实例传入
# xml is speaking
setattr(Per, "talk", f2)  # 增加方法，f需先写好，与类绑定
p.talk()
# xml is talking
delattr(p, "age")  # 删除，同del p.age
print(hasattr(p, "age"))
# False
```

### New方法/单例模式

```py
# NEW方法，单例模式
class Printer:
    tasks = []
    instance = None  # 存放第一个实例对象

    def __init__(self, name):
        self.name = name

    def add_task(self, job):
        self.tasks.append(job)
        print(f"{self.name} is adding task {job}, all are {len(self.tasks)}")

    def __new__(cls, *args, **kwargs):  
        # 只有第一次实例化的时候正常进行，后面每次实例化并不真正创建一个新实例
        if cls.instance is None:  # 进行正常的实例化，并把实例后的对象放在cls.instance里
            cls.instance = super().__new__(cls)
        return cls.instance  # 把以后的实例化，直接返回第一次


p1 = Printer("word")
p2 = Printer("ppt")
p3 = Printer("pdf")
p1.add_task("word file")
p2.add_task("ppt file")
p3.add_task("pdf file")
print(p1, p2, p3)
'''
pdf is adding task word file, all are 1
pdf is adding task ppt file, all are 2
pdf is adding task pdf file, all are 3
<__main__.Printer object at 0x000001E0AF352FD0> <__main__.Printer object at 0x000001E0AF352FD0> <__main__.Printer object at 0x000001E0AF352FD0>
'''
```
