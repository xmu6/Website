# 迭代器

## 简介

- 可迭代对象：可用for循环遍历

- 迭代器：一个可用记住遍历位置的对象，只能往前，不能后退

- 迭代本质：在这个过程中有一个“人”去记录每次访问到了第几条数据，以便每次迭代都可以反悔返回下一条数据，称这个“人”为迭代器。可迭代对象本质就是可以向我们提供一个这样的“人”，即迭代器帮助我们对其进行迭代遍历使用。

- 获取迭代器：

```py
a = [1, 2, 3, 4, 5, 6, 7, 8, 9]
a_iter = iter(a)
print(a_iter)  # <list_iterator object at 0x000002B2AE7FE410>
```

- 判断

```py
from collections.abc import Iterable, Iterator
a = [1, 2, 3, 4, 5, 6, 7, 8, 9]
a_iter = iter(a)
x = isinstance(a, Iterable)
y = isinstance(a_iter, Iterator)
print(x)  # True
print(y)  # True
```

- 通过next()取出数据

```py
a = [1, 2, 3, 4, 5]
a_iter = iter(a)
print(next(a_iter))  # 1
print(next(a_iter))  # 2
print(next(a_iter))  # 3
print(next(a_iter))  # 4
print(next(a_iter))  # 5
```

## 两个方法

- `__iter__`方法与`__next__`方法

​	如果定义类时有`__iter__`方法，则这个类创建出来的对象一定是可迭代对象；

​	若他还有`__next__`方法，则是一个迭代器，作用：①标记当前类创建出来的对象，一定是迭代器。②当调用next（）函数时，这个方法会自动调用

- for循环本质
  1. 先调用`iter() `函数，它会自动调用`__iter__`方法，此方法返回这个可迭代对象的迭代器对象
  2. 对获取的迭代器不断调用`next()`函数，它会自动调用迭代器中的`__next__`方法来获取下一个值
  3. 当遇到`StopIteration`异常后循环结束

# 生成器

## 简介

案例：斐波拉契数列

```py
class Fib:
    def __init__(self):
        self.n1 = 1
        self.n2 = 1

    def __iter__(self):
        return self

    def __next__(self):
        n = self.n1
        self.n1, self.n2 = self.n2, self.n1 + self.n2
        return n
    
    
fib = Fib()  # 利用迭代器
for x in fib:
    print(x)
'''
1
1
2
3
5
.
.
'''
```

什么是生成器？

​	通过列表生成式，我们可以直接创建一个列表。但受内存限制，列表容量有限，而且创建一个包含100万元素的列表不仅占用很大的存储空间，且只需要访问前面几个元素时那后面的空间就白白浪费了。所以如果列表元素可以<u>按照某种算法推算出来</u>，就不必创建完整的list，从而节省大量空间。

​	在python中，这种<u>一边循环一边计算</u>的机制称为生成器：generator。只记录生成数据的方式（算法），而不是事先生成且存储这些数据。<u>生成器是一类特殊的迭代器</u>

## 创建

- 方式一：将列表生成式的`[]`改成`()`

```py
n = [x for x in range(5)]  # 列表
print(type(n))  # <class 'list'>
print(n)  # [0, 1, 2, 3, 4]

m = (x for x in range(5))  # 生成器
print(type(m))  # <class 'generator'>
print(m)  # <generator object <genexpr> at 0x0000018BB9D1B9F0>
```

- 方式二：推算的算法比较复杂时，用<u>函数</u>来自己实现一个生成器

  如果一个函数中有**yield**，那么本来看上去`fib_generator()`是调用函数，此时就变成了<u>创建一个生成器对象</u>，这个对象当做`fib_generator()`的返回值

  使用生成器完成斐波拉契数列：

```py
def fib_generator():
    n1 = 1
    n2 = 1
    while 1:
        n = n1
        n1, n2 = n2, n1 + n2
        # return n
        yield n


fib = fib_generator()
print(type(fib))  # <class 'generator'>
print(next(fib))  # 1
print(next(fib))  # 1
print(next(fib))  # 2
print(next(fib))  # 3
# 因为fib此时是生成器，又是一个迭代器，故可以使用next函数
```

注：如果调用了多次这个def代码块，意味着创建了多个生成器，且每个生成器之间相互独立

## yield关键字

- 只要有yield关键字，虽然看上去是调用函数，实际上是创建一个生成器对象
- 通过`next`调用生成器，可以让这个带有yield的代码块开始执行
  - 如果是第一次执行，从def代码块的开始部分执行，直到遇到yield为止，并把yield关键字后的数值返回，当做`next()`的返回值
  - 如果不是第一次执行，则<u>从上一次暂停的位置执行</u>（即从上一次yield关键字的下一个语句开始执行），直到遇到下一次yield为止，并把yield关键字后的数值返回，当做`next()`的返回值。

- 说明：
  - 如果在调用next的时候，从上一次暂停的位置继续向下运行时，遇不到yield，那么就会产生异常
  - 如果在调用next时遇到return，也会产生异常，并且把return的数值用异常暂时存储起来

```py
def f():
    yield 1
    print("yi")
    return 2
    yield 3


f = f()
print(next(f))  # 1
print(next(f))
'''
yi
Traceback (most recent call last):
  File "C:\Users\Xiaoml1\PycharmProjects\pythonProject\生成器.py", line 67, in <module>
    print(next(f))
          ^^^^^^^
StopIteration: 2
'''
```

- 获取return值，使用异常捕获

  ```py
  def f():
      yield 1
      return 2
  
  
  f = f()
  print(next(f))  # 1
  try:
      print(next(f))
  except StopIteration as ret:
      # 在异常对象的value属性中获取
      print(ret.value)  # 2
  ```

## `send()`唤醒

如果想要生成器继续向下运行，我们可以使用next后send

- 相同点：
  - 都会让生成器继续向下运行
  - 运行时遇不到yield，都会产生异常
- 不同点：
  - next只会让运行继续开始，而send除了可以开始运行之外，还可以将某个数据携带过去

```py
def f():
    while True:
        print(1)
        n = yield 100
        print(2, 'n =', n)


f = f()
print(next(f))
print("——————————————")
print(next(f))
'''
1
100
——————————————
2 n = None
1
100
'''
```

对比

```py
def f():
    while True:
        print(1)
        n = yield 100
        print(2, 'n =', n)


f = f()
print(next(f))
print("——————————————")
print(f.send(11))  # 传入 yield 100 的结果
'''
1
100
——————————————
2 n = 11
1
100
'''
```

注：需在yield之后用`send()`, 若一开始就用send传入非空值会直接报错，因为此时没有yield接收值

# 闭包

即函数中嵌套函数

```py
def person(name):
    def say(content):
        print(f"{name}: {content}")

    return say


p1 = person('张三')
p2 = person('李四')
p1('你好')
p2('再见')
"""
张三: 你好
李四: 再见
"""
```

引用的理解：

```py
def test():
	print('---')
ret = test()  # 引用函数的返回值
ret = test  # 用另一个变量复制了test这个引用，导致ret也指向那个函数代码块
```

定义函数可以理解为定义了一个全局变量，其变量名是函数的名字，这个test变量指向了一个代码块，这个代码块是函数，其实就是说test保存了一个代码块的地址，即引用。

定义：

在函数中可以（嵌套）定义另一个函数，如果内部的函数**引用了外部的函数的局部变量或形参**，则可能产生闭包。把内部函数以及用到的外部函数中的变量称之为闭包。闭包可以用来在一个函数与一组“私有”变量之间创建关联关系。在给定函数被多次调用的过程中，这些私有变量能保持其持久性。

怎样定义：

- 函数嵌套定义
- 内部函数用到外部函数变量
- 外部函数将内部函数的引用返回

```py
def test(num):
    def test_in(num_in):
        print(f"num: {num}, num_in: {num_in}")
        return num + num_in

    return test_in


ret = test(10)
print(ret(100))
print(ret(200))
"""
num: 10, num_in: 100
110
num: 10, num_in: 200
210
"""
```

说明：

- 正常调用函数时，这个函数中的所有局部变量+形参都只会在这个函数执行的过程中才会保留，只要这个函数执行完毕，那么这些局部变量+形参就会被自动释放。
- 而闭包在外部函数执行完毕后，这个外部函数中的所有局部变量+形参都不会被释放，以便于调用内部函数时可以使用。
- 闭包的好处：将局部变量永久存储。
- 闭包的坏处：占用内存。

注意：在闭包的内部函数中，如果没有用特设的关键字来声明外部函数的变量，则不能对其修改。

```py
def counter(start=0):
    def add_one():
        nonlocal start  # 添加nonlocal可以在闭包的内部函数中进行修改，否则报错
        start += 1
        return start

    return add_one
c = counter(5)
print(c())  # 6
print(c())  # 7
```

多个内部函数时(一般只用一个的)

```py
def line_conf(a, b):
    def line1(x):
        return a*x + b
    def line1(x):
        return 2*a*x + 2*b
    return line1, line2  # 返回的是元组

line = line_conf(1,2)
print(line[0](5))  # 7
print(line[1](5))  # 14
```
