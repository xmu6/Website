# 概念

- 并发编程：通过代码编程让计算机在一定时间内同时跑多个程序所进行的编程操作，实现让CPU执行多任务，充分利用CPU以达到最高的处理性能。

- 进程：操作系统**资源分配**和独立运行的最小单位。

  一般由程序段、数据集、程序控制块三部分组成。

  - 程序段：也叫指令集，进程执行过程中需要运行的代码块，存储在内存中对应进程的程序段中。
  - 数据集：进程执行过程中向操作系统申请分配的所需要使用的资源。
  - 控制块：简称PCB，用于记录进程的外部特征，描述进程的执行变化过程，操作系统可以利用它来控制和管理进程，是操作系统感知进程存在的唯一标志。
  - PID（process ID）：是程序被操作系统加载到内存成为进程后动态分配的资源。

- 线程：进程内的一个**任务执行**独立单位，是任务调度和系统执行的最小单位。

- 协程：是用户态的轻量级线程，协程的调度完全右用户控制，主要为了单线程下模拟多线程。

- 并行：多个任务作业在同一时间内分别在各个CPU下执行。多核CPU中才有并行。

- 并发：资源有限情况下（单核CPU），系统调度只能在同一时间执行一个任务，CPU的控制权在多个任务作业中来回快速切换，造成同时执行多个任务的幻觉。

- 同步：一个任务接着一个任务执行。

- 异步：多个任务交替执行。

# 进程

```py
import multiprocessing, time, os

#  基本语法：进程操作对象 = multiprocessing.Process(target=任务)
#  任务可以是一个函数，也可以是一个方法
def watch():
    for i in range(3):
        print("kan...", os.getpid())
        time.sleep(1)
        
if __name__ == '__main__':
    process = multiprocessing.Process(target=watch)
    process.start()  # 创建进程
```
