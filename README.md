# Xiaoml 的个人博客

<div align="center">记录技术、工具与生活，一个持续积累的个人网站。</div>

## 关于

这是我的个人博客，也是我的知识库与作品集，主要分享：

- **技术** — 编程、后端、前端、运维、数据库等方向的实践与踩坑
- **工具** — 觉得好用、有趣的软件与开发工具，以及一些测试工具的使用笔记
- **生活** — 阅读、感悟与日常记录

站点站在 [VitePress](https://vitepress.dev/) 与 Teek 主题之上做了定制化扩展，文章按分类组织，内容详见分类导航。

站点地址：<https://xiaomaolin.cn/>

## 本地运行

项目使用 pnpm 管理依赖。

```bash
git clone https://github.com/xmu6/Website.git
pnpm install
pnpm docs:dev      # 本地开发预览
pnpm docs:build    # 生产构建
```

## 部署

站点已部署在 [Cloudflare](https://www.cloudflare.com/) 上。
